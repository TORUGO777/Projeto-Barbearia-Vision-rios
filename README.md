💈 Barbearia Visionários

Projeto desenvolvido com o objetivo de criar um sistema web para gerenciamento de uma barbearia, facilitando a organização dos serviços, profissionais e agendamentos.
A aplicação foi desenvolvida utilizando Java e Spring Boot, aplicando conceitos de desenvolvimento back-end, organização em camadas e integração entre controladores, modelos e repositórios.

🚀 Funcionalidades

- Página inicial: interface principal do sistema.
- Gerenciamento de profissionais: cadastro e listagem dos profissionais da barbearia.
- Gerenciamento de serviços: organização dos serviços disponíveis.
- Gerenciamento de agendamentos: cadastro e visualização dos agendamentos.
- Interface web: páginas desenvolvidas com HTML e CSS.

🛠️ Tecnologias utilizadas

- Java
- Spring Boot
- Maven
- HTML5
- CSS3
- Thymeleaf

📚 Conceitos aplicados

Durante o desenvolvimento, foram trabalhados conceitos importantes, como:

- Programação Orientada a Objetos (POO).
- Arquitetura MVC (Model-View-Controller).
- Desenvolvimento de aplicações web.
- Organização de código em camadas.
- Utilização de Controllers, Models e Repositories.

🎯 Objetivo do projeto

Este projeto faz parte da minha jornada de aprendizado em desenvolvimento de sistemas, permitindo colocar em prática conhecimentos de Java, desenvolvimento web e organização de aplicações utilizando Spring Boot.
O desenvolvimento também contribuiu para ampliar minha experiência na construção de sistemas funcionais e na aplicação de conceitos fundamentais da programação.
